# Catan Board Generator

Random board generator for Catan using custom rules.

![TypeScript](https://img.shields.io/badge/TypeScript-222222?style=for-the-badge&logo=typescript)
![Vite](https://img.shields.io/badge/Vite-222222?style=for-the-badge&logo=vite)

- Resource tile placement using wave function collapse algorithm
- Adjustable rule sets that keep matching resources from clumping
- SVG rendering of the generated board
- Number tokens and harbors in progress
